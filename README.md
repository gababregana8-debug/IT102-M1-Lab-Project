# IT102 M1 Lab Actual Exam – Part 3

## Python Project Prototype

This project is a Python application prototype created for the IT102 M1 Lab Actual Exam Part 3.

The program demonstrates the navigation and user flow of the application using Object-Oriented Programming (OOP) concepts.

## Features

* Main Menu
* Services
* Service Details
* User Profile
* Help
* Exit

## Technology Used

* Python
* Object-Oriented Programming (OOP)

## How to Run

1. Download the `main.py` file.
2. Open it using Python IDLE or another Python IDE.
3. Run the program.
4. Follow the menu options to navigate through the application.
